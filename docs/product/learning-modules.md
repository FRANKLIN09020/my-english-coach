# Learning modules by CEFR level

Every learner receives an adaptive path after assessment. Each path has four modules with lessons, guided practice, AI feedback, and a review checkpoint.

| Level | Learner outcome | Modules |
| --- | --- | --- |
| A1 | Basic survival English | Everyday foundations, simple sentences, listen and speak, daily habit |
| A2 | Familiar conversations | Daily life, past and future, real-world listening, confidence practice |
| B1 | Independent communication | Clear communication, grammar control, work English, fluency routine |
| B2 | Professional fluency | Advanced conversation, professional writing, fast comprehension, precision feedback |
| C1 | Flexible advanced use | Nuance, influential communication, critical comprehension, polished output |
| C2 | Near-native control | Masterful expression, high-stakes communication, cultural fluency, refinement |

Each module should eventually include lessons, exercises, AI-scored submissions, spaced review, and a mastery check.
